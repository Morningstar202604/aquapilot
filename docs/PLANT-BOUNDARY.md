# WP2 全厂边界：ASM2d 生物除磷 + ADM1 泥线闭环

> 适用范围：`src/sim/asm2d.ts`、`src/sim/asm2dNetwork.ts`、`src/sim/adm1.ts`、
> `src/sim/sludgeLine.ts`、`src/sim/plantBoundary.ts`、主引擎 `networkEngine.ts` 的 `asm2d` 路径。
> 本文只描述代码内可验证的口径；现场验收门见 `docs/INDUSTRIAL-READINESS-PLAN.md` 第 6 节。

## 1. 范围与默认开关

- 主引擎 `KineticModel` 三档：`simple`（经验动力学）、`asm1`（13 组分）、`asm2d`（19 组分生物除磷）。
- 泥线与全厂账本**默认关闭**：`createNetworkState({ model: 'asm2d', plantEnabled: true })` 才初始化
  `state.plant`；缺省时 `plant` 为禁用状态，ASM1 / simple 基准路径与既有测试数值不变。
- 关闭泥线时不产生沼气、不回流滤液；账本仍可按水线自身口径累计（`enabled=false`）。

## 2. 单位（契约 §2）

| 量   | 单位                              |
| ---- | --------------------------------- |
| 流量 | m³/h                              |
| 浓度 | mg/L（= g/m³）                    |
| 质量 | kg                                |
| 时间 | min（引擎步进）；报表换算 d       |
| 功率 | kW；电耗 kWh                      |
| 沼气 | m³/d（STP）；CH₄ 密度 0.717 kg/m³ |

所有浓度不得为负或非有限值；ASM2d / ADM1 组分越界时在反应器物理边界钳制
（负值/非有限 → 0，超上限 → 工程边界上限）并记录 `ASM2D_STATE_INVALID` 诊断，不在展示层修数。
当前工程边界上限（`asm2dNetwork.ts` 的 `BOUNDS`）：溶解态 NH4/NO3 ≤120 mg/L、PO4 ≤30 mg/L、
DO ≤10 mg/L；颗粒态生物量 ≤15000 g COD/m³、X_PP/X_PHA ≤5000 g COD/m³。

## 3. ASM2d 网络级求解路径

### 3.1 真实积分，不做结果投影

`modelMode === 'asm2d'` 时，`solveReactors` 直接调用 `asm2dNetwork.ts` 的
`stepAsm2dNetwork`，**逐池对 19 组分做 CSTR 积分**；反应器持有的 `asm2d` 状态向量就是被积分的对象，
聚合量（COD/NH/NO3/TP/DO/碱度）只是从组分导出的视图，不再反向覆盖组分。

- **平流**：按拓扑序处理反应器；入流 = 上游出流 + 内回流 + RAS + 厂外来水，按各边流量加权混合
  （`mixInflow`），不是全池同浓度。RAS 颗粒态按 Takács 底流浓缩倍数（1–6）缩放，溶解态不缩放。
- **反应**：速率骨架复用 `buildAsm2dRates` + `buildAsm2dStoichiometry`（`asm2d.ts`），
  速率常数按 d⁻¹ 给出；网络积分时反应项乘 `子步长(d) = 子步长(h) / 24`。
- **子步**：显式欧拉，子步长上限 1 min；按本步长等分（最多 20 子步）。好氧池在每个子步内按
  设定 DO 维持溶解氧（风机跟踪设定值），否则首个子步耗尽残留 O₂ 后，后续子步好氧生长/硝化的
  monod(O₂) 全为 0，反应只在第一子步发生。单池、串联两池、带 RAS 三池探针均稳定，无 NaN、
  无大面积贴边界、无发散。
- **二沉池**：进料固体由 ASM2d 颗粒态（`X_I+X_S+X_H+X_PAO+X_AUT`，PP/PHA 胞内聚合物不计入
  进料固体）按 1.42 kgCOD/kgVSS 折算；RAS 浓缩颗粒态按比例回首池，出水 SS 取溢流层，WAS 按
  `wasRatio` 抽固体。MLSS、SRT、`biomassKg` 全部从组分汇总：MLSS 取总颗粒态口径，SRT 另按
  活性生物量（X_H+X_PAO+X_AUT）计。
- **回流口径（仅 asm2d 模式，simple/asm1 不变）**：内回流比限到 0.5–1.0 Q；排泥比限到
  0.6%–1.5% Q（对应 SRT 约 12–18 d）；RAS 底流按缺氧/无溶解氧处理，回流前在二沉池内反硝化，
  不把好氧末段 NO₃ 带回厌氧池抑制 PAO 储存。
- **进水映射**：按 BSM2 城市污水典型分馏（非现场实测）：COD 分 S_A 0.085 / S_F 0.085 /
  S_I 0.09 / X_S 余量 / X_I 0.07 / X_H 0.02；N 主要进 S_NH4，原水 S_NO3 近似 0
  （tn−nh 余量为溶解性有机氮，骨架未单列组分）；P 全进 S_PO4；碱度 S_ALK = alk/50。

### 3.2 骨架之外的两个网络级补充过程

骨架 19 过程未单列以下三项，`reactionVector` 在网络级补上（代码注释已注明）：

1. **溶解性发酵** S_F → S_A：仅厌氧/缺氧条件，速率取参数表预留的 `q_fe`，受 S_F 半饱和与 DO 开关
   抑制；否则 S_F 在池内累积、S_A 被耗尽，异养菌与 PAO 都会饿死。
2. **异养生长基质扩到 S_F**：骨架 monod 只看 S_A；网络级用代理态 `S_A' = S_A + S_F` 估算速率，
   uptake 按 S_A/S_F 浓度比例分担到两个溶解态组分。
3. **好氧吸磷（PP 储存）**：骨架未单列独立的聚磷酸盐储存步骤；网络级在好氧段、生物除磷开启时，
   PAO 以胞内 PHA 为能源/碳源，吸收溶液态正磷合成 `X_PP`，与厌氧段 S_A→X_PHA 释磷储存构成
   「厌氧释磷 / 好氧吸磷」循环。速率受 X_PHA 与 S_PO4 半饱和限制；PHA 不足时该步骤速率趋近 0。

### 3.3 19 组分

溶解态：`S_I, S_F, S_A, S_NH4, S_PO4, S_NO3, S_O, S_N2, S_ALK`；
颗粒态：`X_I, X_S, X_H, X_PAO, X_AUT, X_PP, X_PHA`。
完整清单与过程见 `asm2d.ts`。

### 3.5 三条除磷路径

1. **厌氧释磷**：厌氧池 `S_O≈0、S_NO3≈0`，PAO 分解 `X_PP` 释放正磷、吸收 VFA 合成 `X_PHA`，
   表现为 `S_PO4` 上升、`X_PHA` 上升。
2. **好氧吸磷**：好氧池充氧后 PAO 储存 `X_PP`，`S_PO4` 下降、`X_PP` 上升。
3. **PAO 胞内循环**：`X_PHA`（厌氧合成/好氧与缺氧段消耗）与 `X_PP`（厌氧消耗/好氧合成）反向消长。
4. **PAC 化学除磷**：独立于生物路径，由 `controls.pacDose` 控制，在出水阶段按
   `pacDose × 0.06 kgP/kgPAC` 扣除出水 TP；生物除磷与化学除磷可叠加，也可分别关掉做对照。

生物除磷总开关：`createNetworkState({ bioPRemoval: false })` 关闭 PAO 相关过程，TP 只能靠 PAC 与
排泥去除，用于对照实验。

## 4. 泥线拓扑与参数来源

```
WAS 剩余污泥 → 重力浓缩池 → 厌氧消化池(ADM1 CSTR, 35 ℃) → 脱水 → 泥饼外运
                  │上清液回流──────────────────┐
```

### 4.2 沼气与能耗

- VS 降解量 → CH₄ 产量 → CO₂ 按 CH₄/CO₂ 比例折算；CH₄ 质量 = 体积 × 0.717 kg/m³。
- 加热功率 = 进料质量流量 × 比热 ×（35 − 环境温）/3600；搅拌功率按池容计。
- 脱水滤液携带 NH4-N、COD、TP 回流到首端。污泥结合氮 = 干固体 × 0.07；VS 降解部分矿化的氮
  （`sludgeBoundN × vsDestruction`）进液相滤液，其余结合氮随泥饼排出，滤液铵 = 进料氮 + 矿化氮。
  30 d 实测滤液 NH4-N 约 160.6 mg/L（低于工程目标 500–1500 mg/L 区间，消化池生物量分解释放的铵
  仍未单独建模），开启泥线后进水 NH4 负荷可见抬升；COD/TP 回流已入账。

## 5. 全厂三本账（COD / N / P）

每步按流量 × 浓度 × 时长积分（g/m³ × m³/h × h ÷ 1000 = kg），自预热结束起累计。
库存项在首步只记录存量基线、不记增量（避免 `previous=0` 制造巨额假库存）。

| 行式                         | COD 账                       | N 账                         | P 账                                  |
| ---------------------------- | ---------------------------- | ---------------------------- | ------------------------------------- |
| 进水 `inflowKg`              | 进水 COD                     | 进水 TN                      | 进水 TP                               |
| 出水 `effluentKg`            | 出水 COD                     | 出水 TN                      | 出水 TP                               |
| 排泥 `wastedKg`              | 干固体 × 1.42                | 干固体 × 0.07                | 干固体 × 0.032                        |
| 沼气 `methaneCodKg`          | CH₄ 质量 × 4.0 kg COD/kg CH₄ | —                            | —                                     |
| 氧化 `oxidizedKg`            | OUR 折 COD：仅 `OUR_hetero`（异养生长 + 内源呼吸），`OUR_nitro`（氨氧化/亚硝化）单独一行、不计入 COD 账 | — | — |
| 反硝化 `denitrifiedKg`       | —                            | NO₃ 还原通量 × 计量系数 → N₂ | —                                     |
| 库存变化 `inventoryChangeKg` | 各组分浓度 × 池容的期末−期初 | 组分级结合氮（活体 ×`i_N_BM` + X_S ×`i_N_XS`）存量差 | 组分级结合磷（活体 ×`i_P_BM` + X_PP ×`i_P_PP`）存量差 |
| 回流 `recycleKg`             | 滤液 COD                     | 滤液 NH4-N                   | 滤液 TP                               |

- **独立通量审计，不做余额倒推**：N₂ 由反硝化过程 NO₃ 还原通量 × 计量系数积分；COD 氧化由曝气
  需氧量（OUR）路径折算，硝化耗氧按 4.57 kgO₂/kgN 扣除后再折 COD；CH₄ 由 ADM1/泥线产气 × 4.0
  kgCOD/kgCH₄；库存 = Σ(组分浓度 × 池容) 的期末−期初代数差。
- 残差 = 进水 + 回流 − 出水 − 排泥 − 沼气COD − 氧化 − 反硝化N₂ − 库存变化；残差是无法解释的差额，
  **允许为非零小数**，不再用剩余项倒填氧化/N₂。
- 闭合判据：`|残差|/(进水+回流) ≤ 5%`；超阈值记 `PLANT_BALANCE_UNCLOSED` 诊断
  （**不阻断仿真**，在快照与 `/api/plant/balance` 可见）。
- 甲烷 COD 当量：`CH₄ + 2O₂ → CO₂ + 2H₂O`，64/16 = 4 g O₂/g CH₄。

## 6. 与 BSM2 参考的差异

- BSM2 含初沉池、两段厌氧/好氧、完整污泥侧（浓缩、消化、脱水、沼气储气）与全年动态进水；
  本包泥线是单段 CSTR 近似，未做初沉污泥与剩余污泥分质、未做两相消化。
- 进水序列可接 BSM2 官方常量向量（`influentSeries`），但泥线回流负荷是本包模型生成，
  不与 BSM2 动态沼液曲线逐点对齐。
- ASM2d 参数未做 BSM2 校准；对照基准仍是 BSM1 Table 6（`bsm1-benchmark.test.ts`），
  该路径走 ASM1/simple，不受本包影响。

  部分运行略低于工程目标 500–1500 mg/L。泥线回流使进水 NH4-N 负荷可见抬升（开启 vs 关闭对照用例通过）。
- 无鸟粪石（MAP）回收、无化学除磷泥量单独计账。
- 消化池未做水力/温度分层、两相厌氧、沼气脱硫与储气；未做沼气发电并网与热电联产收益。
- 多系列污泥在各消化池之间的独立分配、各池独立进料浓度，暂取全厂口径（系列固体分配归后续边界细化）。
- COD 氧化由 `OUR_hetero` 路径折算 + 内源呼吸入账，硝化耗氧 `OUR_nitro` 单独成行、不计入 COD 账；
  但异养生长耗氧系数、子步累计口径与衰减残余 `f_p` 尚未校准，氧化项仍高估（§5.1）。
- 泥线设备故障（搅拌停机、加热失效、消化池酸化）未建故障注入，归 WP4 控制层。

## 8. 可观测口径
