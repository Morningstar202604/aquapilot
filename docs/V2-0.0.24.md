# AquaPilot V2 0.0.24 验收：服务运行时真实 Modbus 轮询与写入

> 基线：0.0.23 / `8c1bbb9`。本批把真实 Modbus 从独立 `gateway-check` 接进 `IndustrialHub`：启动时按配置轮询，点位 API 返回真实读数，写入先过真实 Function 06 再落审计。
> 质量门：`cargo fmt --all --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace` 全过（101 项）。

## 已做完

### 配置与轮询

- `AQUAPILOT_GATEWAY_CONFIG=/path/gateway.json` 启用真实模式；不设则保持 0.0.17 的 `MOCK` 行为。
- `AQUAPILOT_GATEWAY_POLL_SECONDS` 默认 15 秒，范围 2–3600。
- 服务启动后在 tokio blocking 线程里轮询；`IndustrialHub::poll_once()` 也可单独调用。
- Modbus `read` 映射把 `raw × scale + offset` 写回同名点位；成功后 `quality=good`，失败标 `bad`，不伪造旧读数。
- `GET /api/v1/industrial/adapters` 在真实模式返回 `real=true`、`last_check` 与真实 `connected/error`；`GET /api/v1/industrial/points` 返回更新后的值。
- 配置解析失败不崩溃：adapter 状态 `config_error`，轮询不启动。

### 真实写入与审计顺序

- `modbus.write` 映射：
  ```json
  {"point_id":"influent.flow","register":10,"scale":1,"offset":0}
  ```
- `POST /api/v1/industrial/write` 先做点位范围校验，再发真实 Modbus Function 06，校验 echo 的 register/value；成功后才更新镜像并写 SHA-256 审计链。
- 没有 `modbus.write` 映射返回 409 `NO_WRITE_MAPPING` / `POINT_NOT_MAPPED`；连接失败返回 502 `GATEWAY_WRITE_FAILED`，点位与审计都不改。
- 不再出现“镜像改了、审计写了、PLC 没收到”的假成功。

### 实机验收

- 本地真实 Modbus TCP 服务（15021），寄存器 0 返回 150，寄存器 10 接受 Function 06。
- 5203 服务带 `AQUAPILOT_GATEWAY_CONFIG`、2 秒轮询启动，版本 0.0.24。
- 轮询后 `influent.flow` = 1500（150 × 10），`quality=good`；adapter `connected=true`、`real-tcp`。
- 写入 2000：真实 Function 06 发送到寄存器 10，echo 通过；响应 `previous_value=1500`、`value=2000`；审计 #1 `industrial.write`，previous 1500 → new 2000。
- 失败路径单测：未映射 409、连接拒绝 502，点位保持 1000、审计 0 条。
- 证据：`docs/cutover/gateway-runtime-modbus-0.0.24.json`。
