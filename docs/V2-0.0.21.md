## 已做完

### 反应器库存

`ExperimentAnalysis.inventory` 新增，从 `result.reactors` 的浓度与池容推导：

- 每个池：`C × V / 1000`，输出 COD、氮、磷、MLSS 的 kg 量；MLSS 优先取 `mlss`，缺失时取 `ss`。
- 整厂汇总：`total_cod_kg / total_nitrogen_kg / total_phosphorus_kg / total_mlss_kg`。
- 氮优先取 `tn`，否则取 `nh4_n + no3_n`。
- `note` 明确这是**反应器库存**，不含二沉池与三级过滤固体，不是整厂库存证明。
- 单测 `inventory_is_derived_from_reactor_state_and_volume` 覆盖池级与汇总数值。

### ASM2d 30 天对照

新增同几何 ASM2d 配置 `docs/cutover/translated-a2o-asm2d.json`：5 池（3000 / 4500 / 5750 ×3 m³）、二沉池 4800 m² × 4.5 m、进水 1800 m³/h、内回流 2Q、RAS 0.8Q、WAS 0.022Q、`v_max=240 m/d`；进水沿用旧水线 COD/NH4-N/TP 量级。

实机实验 `03bd6c0a-d89c-4106-8f7c-1042842439ec`，`succeeded`，30 天：

- 出水 COD 85.33、SS 46.30、NH4-N 0.219、TN 12.37、TP 4.95 mg/L；BOD5 引擎不输出，保持 `null`，不估算。
- 评分 33.3（2/6），COD / SS / TP / PO4-P 超限；NH4-N、TN 通过。
- 三本账全部闭合：COD 残差 2.22%、氮 0.50%、磷 0.46%。
- 反应器库存：COD 60 580 kg、氮 3 016 kg、磷 2 125 kg、MLSS 50 476 kg；5 个反应器逐池数值见 summary。
- 证据：`docs/cutover/asm2d-30d-v2-summary.json`、`asm2d-30d-v2-full.json`、`asm2d-30d-v2-samples.csv`、`asm2d-30d-v2-report.md`。
- 明确不把旧 TypeScript ASM2d 当 oracle：旧 30 天 NH4-N 均值 28.19 mg/L、三本账最大残差 70.6%，不能支撑六项 parity。BOD 缺失使“六项完整对照”不成立，本批不宣称。
