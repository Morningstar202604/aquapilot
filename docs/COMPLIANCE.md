# WP6 合规与报表口径说明

> 版本：2026-11-23　归属：WP6 合规（`src/sim/sampling.ts`、`src/sim/compliance.ts`、`src/server/routes/compliance.ts`）
>
> 本文锁定报表的统计口径。任何与本文冲突的实现以本文为准；许可证口径变更时，先改本文再改代码。

## 1. 为什么不能用分钟瞬时值算达标率

早先界面上的「达标率」直接拿每分钟的出水读数和限值比较。这是**假口径**：

- 许可证考核的是**日混合样 / 24h 均值 / 月均值 / 95 分位**，瞬时抓样只用于异常排查，不构成考核样本；
- 分钟数不能当达标率分母：一天 1440 个分钟读数里，缺测、仪器故障、QA 作废的分钟都会被混进去，算出来的百分比既不可复核，也无法追溯到具体样品；
- 高流量时段对出水水质的贡献更大，简单算术平均会低估高负荷时段的浓度，必须按流量加权。

WP6 起，报表里的每一个统计值都能追溯到具体样品 id、样品类型与 QA 状态；作废样品不进统计。

## 2. 样品模型（`src/sim/sampling.ts`）

### 2.1 样品类型

| 类型             | 代码        | 用途                                 |
| ---------------- | ----------- | ------------------------------------ |
| 流量比例日混合样 | `composite` | 24h 流量加权，是日均值考核的法定样本 |
| 瞬时抓样         | `grab`      | 异常排查、抽查；不参与日均值考核     |

### 2.2 日混合样流量加权

窗口内同一指标的混合样浓度按流量加权：

```
C_mix = Σ(Cᵢ · Qᵢ) / ΣQᵢ
```

- `Cᵢ` 为第 i 个分钟读数浓度（mg/L），`Qᵢ` 为对应流量（m³/h）；
- 缺测读数在加权时跳过；窗口内某指标无任何有效读数时，该指标样品判 `void`；
- 总流量 ≤ 0 时加权结果为 null，不参与统计；
- **加权均值不等于算术均值**：高低流量交替时，加权结果偏向高流量时段的浓度。测试用例专门构造了这种情形并断言两者不相等。

### 2.3 样品链与滞后

每份样品记录两个时刻：

- `sampledAtMin`：采样时刻；
- `resultAvailableAtMin`：实验室结果可用时刻 = 采样时刻 + 结果滞后（`resultLagMin`，按样品类型配置）。

报表按采样时刻归窗口；结果尚未出实验室的样品，其 QA 状态由调用方在喂入前完成判定。

### 2.4 检出限（<DL）与删失

读数低于指标检出限 `detectionLimit` 时，按 `belowDlRule` 处理：

| 规则              | 统计取值   | 说明                     |
| ----------------- | ---------- | ------------------------ |
| `half-dl`（默认） | 1/2 DL     | 环境统计常用保守替代值   |
| `zero`            | 0          | 按未检出计零             |
| `raw`             | 保留实测值 | 标 `belowDL`，不替换数值 |

删失标记 `censored` 表示数值被规则替换过；`belowDL` 表示原始值低于检出限。CSV 与 JSON 都保留这两个标记，事后可改规则复算。

### 2.5 留样时限（holding time）

`resultAvailableAtMin − sampledAtMin > holdingTimeMin` 时样品判 `void`（无效），不进统计。默认留样时限 24h，按现场实验室规范配置。

### 2.6 平行样 RPD 与校准有效性

- 平行样相对偏差：`RPD = |A − B| / ((A + B)/2) × 100%`；超过 `rpdLimitPct`（默认 20%）判 `qa-failed`；
- 校准失效（`calibrationValid = false`）时，全部指标判 `qa-failed`；
- QA 判定顺序：留样超期 → `void`；校准失效 → `qa-failed`；RPD 超限 → `qa-failed`。

### 2.7 样品三态

| 状态        | 含义                          | 是否参与达标统计 |
| ----------- | ----------------------------- | ---------------- |
| `accepted`  | QA 通过，结果可用             | 是               |
| `qa-failed` | RPD 超限 / 校准失效，作废留痕 | 否               |
| `void`      | 缺测 / 留样超期 / 数值非法    | 否               |

非 `accepted` 的指标 `value` 置为 null，下游统计拿不到作废数值。

## 3. 合规统计（`src/sim/compliance.ts`）

### 3.1 日 24h 均值

- 只由 `accepted` 的日混合样计算；同一天有多份合格混合样时取算术平均；
- 抓样不参与日均值考核。

### 3.2 月度滚动均值

窗口内最近 `monthWindowDays`（默认 30）个有效日值的算术平均；**缺测日不补零**，窗口内有效日不足时按实际有效日计算，并在 `monthlyMeanDays` 标注实际使用天数。

### 3.3 95 分位

- 样本：最近 `p95WindowDays`（默认 30）个日值；
- 算法：升序排序后按 **type-7 线性插值**（numpy / R 默认口径）：

```
rank = 0.95 × (n − 1)
P95 = x[⌊rank⌋] + (rank − ⌊rank⌋) × (x[⌈rank⌉] − x[⌊rank⌋])
```

- n = 1 时返回唯一值；空集返回 null。不使用最近邻或向上取整等其它分位法。

### 3.4 达标率分母

```
达标率 % = 达标有效考核日 / 有效考核日 × 100
```

- **有效考核日**：当天至少有一份该指标的合格混合样；
- 分母不是分钟数，也不是窗口总天数；无有效考核日时 `complianceRatePct = null`，不出百分比。

### 3.5 数据完整率

```
完整率 % = 有效考核日 / 窗口内应考核日 × 100
```

应考核日按窗口覆盖到的自然日桶计算；采样缺失、仪器故障、QA 作废造成的缺测日计入缺失。

### 3.6 超标记录

- `exceedDayCount`：日均值超标的天数；`exceedSampleCount`：合格样品级超标条数；
- `maxExceedRatio`：最大超标倍数（value / limit）；`maxExceedAmount`：最大超标幅度（mg/L，value − limit）；
- 判超标用严格大于限值（限值口径为「≤ 限值」）。

## 4. 报表导出

- JSON：`/api/compliance/report?from=&to=&format=json`，返回完整 `ComplianceReport`；
- CSV：`format=csv`，一行 = 一份样品 × 一个指标，字段含：指标、限值、样品值、样品类型、采样时间、结果可用时间、QA 状态、是否低于检出限、是否删失、判定、统计口径、样品 id、数据来源标识；
- CSV 转义由 `csv-stringify` 处理，不手写引号转义；
- 样品明细：`/api/compliance/samples?from=&to=`。

### 错误码

| 错误码                  | HTTP 状态 | 触发                                                 |
| ----------------------- | --------- | ---------------------------------------------------- |
| `PERMIT_WINDOW_INVALID` | 400       | 时间窗非法：非有限数、to < from、超窗宽、format 非法 |
| `COMPLIANCE_NO_SAMPLES` | 422       | 窗口内没有合格样品，无法出具合规统计                 |

## 5. 许可证参数从哪来

以下参数属于**现场许可证与实验室规范**，代码只提供可配置项与默认值，不代表本厂址的法定口径：

| 参数         | 配置项                        | 默认值                                                 | 现场来源                  |
| ------------ | ----------------------------- | ------------------------------------------------------ | ------------------------- |
| 排放限值     | `limits`（standards.ts 档案） | GB 18918-2002 一级 A                                   | 排污许可证 / 地方排放标准 |
| 日混合样窗口 | `compositeWindowMin`          | 1440 min（24h）                                        | 许可证采样频次条款        |
| 结果滞后     | `resultLagMin`                | 混合样 24h / 抓样 4h                                   | 实验室流程                |
| 检出限       | `detectionLimit`              | COD 2 / BOD 2 / SS 1 / NH 0.05 / TN 0.1 / TP 0.02 mg/L | 实验室方法检出限          |
| <DL 规则     | `belowDlRule`                 | `half-dl`                                              | 许可证 / 监测规范         |
| 留样时限     | `holdingTimeMin`              | 24h                                                    | 水质样品保存时限规范      |
| RPD 阈值     | `rpdLimitPct`                 | 20%                                                    | 实验室 QA/QC 规程         |
| 95 分位窗口  | `p95WindowDays`               | 30 日                                                  | 许可证考核周期            |
| 月均窗口     | `monthWindowDays`             | 30 日                                                  | 许可证考核周期            |

`dataSource` 标识数据来源（`synthetic` / `online` / `lab` …）；仿真数据在报表中显式标注，不冒充现场实测。

## 6. 未做项（不在代码内承诺）

- **法定签字与备案**：报表引擎不出具具有法律效力的报告；签字、盖章、上报备案由现场责任人员完成；
- **实验室 LIMS 对接**：样品结果由调用方喂入，代码不直连 LIMS、不接收实验室原始报文；
- **真实 QA/QC 流程**：平行样、加标回收、空白样等由现场实验室完成；代码只记录传入的 RPD 与校准状态；
- **采样频次自动调度**：代码按喂入的读数归组出样，不驱动真实采样器；
- **历史许可证口径库**：限值档案来自 standards.ts，不内置各地地方标准逐条对照。

## 7. 边界与迁移

- 样品、统计结果均为纯 JSON 结构，旧快照缺字段时走默认配置，不抛错；
- 本模块不读服务器内部状态，输入为显式分钟读数数组；集成方负责把 TrendPoint / 快照行映射成 `MinuteReading`；
- 报表数值不出现 NaN / Infinity：算不出来即返回 null 或错误码，不把缺失伪装成 0。
