# WP5 标定与不确定性口径说明

> 版本：2026-11-23　归属：WP5 标定与不确定性
> （`src/sim/calibration.ts`、`src/sim/uncertainty.ts`、`src/server/calibrationService.ts`、`src/server/routes/calibration.ts`）
>
> 本文锁定标定观测口径、区间算法、相关矩阵解读与可辨识性判据。任何与本文冲突的实现以本文为准。

## 1. 边界先说清楚

**没有现场历史数据时，本模块输出的区间是合成数据上的算法验证，不是这座厂的置信区间。**

- 现场标定验收门（`docs/INDUSTRIAL-READINESS-PLAN.md` 第 6 节）要求至少 2 周历史数据：进出水、池内剖面、DO/MLSS、泥位、药剂、电耗；
- 在拿到这组数据之前，`dataSource` 一律标为 `'synthetic'`；输出里的区间、标准误、相关系数只能证明「算法在已知真值的合成模型上行为正确」，不能解读为某座真实水厂参数的可信度；
- 数据来源为 `'field'` 只在接入现场观测台账后由调用方标注，模块本身不假设输入是现场数据。

## 2. 观测模型与权重

### 2.1 观测结构

标定数据集（`CalibrationDataset`）分两层：

| 层       | 字段                                                            | 说明                                             |
| -------- | --------------------------------------------------------------- | ------------------------------------------------ |
| 出水     | `effluent`：`cod / ss / nh / tn / tp?`                          | 沿用旧 `EffluentObservation`，旧调用路径行为不变 |
| 池内剖面 | `profiles[]`：`reactorId` + `do / nh / no3 / mlss / tp? / po4?` | WP5 新增；字段全部可选，缺测不补零、不进目标函数 |
| 权重     | `weights`                                                       | 按指标覆盖默认归一化                             |
| 时标     | `timestampsMin?`                                                | 采样时标，仅用于审计展示                         |

旧 `CalibrationTarget { observed, weights }` 仍然受支持，`datasetFromTarget()` 适配成新数据集；不传剖面时，目标函数与既有标定结果完全一致。

### 2.2 量程归一化（避免 MLSS 独占目标）

不同指标量级差几个数量级：NH 约 1–5 mg/L，MLSS 约 2000–4000 mg/L。直接把残差相加，MLSS 的平方残差会压过一切。

- **出水部分**：沿用相对误差口径，分母 `max(|观测值|, 1e-3)`，保留旧标定的数值行为；
- **剖面部分**：按参考量程归一化（`PROFILE_REFERENCE_RANGE`：DO 4、NH 5、NO3 10、MLSS 3000、TP 2、PO4 2，单位 mg/L），分母不用观测值——剖面指标观测值可能接近 0，相对误差会被放大成数值噪声。

目标函数输出**分组残差**（`objectiveBreakdown`）：出水行与剖面行分开列出，每行带归一化残差与权重。可以直接看出「出水拟合好、池内拟合差」这类结构性偏差，而不是只看一个总和。

## 3. 参数区间算法（残差自助法）

### 3.1 方法

区间用**残差自助法（residual bootstrap）**，不是拍脑袋的「±10%」，也不是解析近似：

1. 在数据上做点估计 θ̂，取出逐行残差 `rᵢ = 观测ᵢ − 预测ᵢ`；
2. 对每个自助样本：有放回地重抽样残差下标，重构观测 `观测'ᵢ = 预测ᵢ + rⱼ`；
3. 对重构观测重新做有界坐标下降拟合（单坐标三分搜索线搜索，随机化坐标顺序），收集一组参数样本 θ*；
4. 重复 B 次（默认 40，测试用 30）；
5. 90% 区间 = 自助样本的 P10/P90；标准误 = 样本标准差（n−1）。

所有随机数走固定 seed 的 `mulberry32`，同 seed 可复现。

### 3.2 为什么不用 profile likelihood

本轮实现选自助法：它在小维度（≤11 个可标定参数）下不需要似然假设，且区间直接来自重优化样本。profile likelihood（逐参数扫描、其余参数重优化）留作后续可替换方法，接口 `analyzeUncertainty` 的入参形状不变。

### 3.3 区间可读性判据

- **贴边（atBound）**：点估计落在物理边界 5% 带宽内；
- **平坦（flat）**：区间相对宽度 `(P90−P10)/|估计值| > 0.6`，说明数据对该参数近乎没有约束。

## 4. 参数相关矩阵解读

相关矩阵由**标定解处的灵敏度矩阵**导出，不用自助样本计算：

1. 中心差分求灵敏度矩阵 S（观测行 × 参数），元素为归一化残差对参数的偏灵敏度；
2. Gauss-Newton 协方差 `C = (S·Sᵀ)⁻¹`（对角加 1e-8 脊正则）；
3. 相关系数 `rᵢⱼ = Cᵢⱼ / √(Cᵢᵢ Cⱼⱼ)`，输出相关系数而不是协方差。

**符号口径**：两列灵敏度平行（参数不可区分）时，C 的非对角项为**强负相关**——这是补偿方向：一个参数上升必须由另一个下降抵消。`|r|` 越大越不可区分；读数时看绝对值，负号表示此消彼长的补偿关系。

不用自助样本算相关的原因：近退化方向上重拟合会塌缩到同一特解，抽样方差接近零，相关系数被优化器坐标顺序偏置污染；局部灵敏度矩阵在解处直接反映参数方向是否可区分。

## 5. 可辨识性判据

命中任一条即判 `CALIBRATION_NOT_IDENTIFIABLE`，结果里带具体原因：

| 判据     | 阈值                       | 含义                           |
| -------- | -------------------------- | ------------------------------ |
| 贴边界   | 点估计距边界 < 5% 边界跨度 | 边界外不可辨识，参数被边界顶住 |
| 区间平坦 | 相对宽度 > 0.6             | 数据约束平坦，区间过宽         |
| 强相关   | `                          | r                              | > 0.95` | 两个参数不能同时被数据区分 |

### 5.1 数据充分性门

出现以下任一情况，抛 `CALIBRATION_INSUFFICIENT_DATA`，**不返回点估计冒充标定完成**：

- 剖面为空、只有出水指标；
- 观测点数 < 参与拟合参数数 × 2。

观测点计数：出水每个有限指标 1 点，剖面每个有限测量 1 点。

## 6. 预测不确定性（蒙特卡洛）

`monteCarloPrediction` 给出出水 COD/NH/TN/TP 的 P10/P50/P90：

- 参数抽样：每个区间参数按 `估计值 + N(0, SE)` 抽样，截断到物理边界；SE 为 0 时取点估计；
- 逐条参数样本跑预测器，收集出水指标；
- **分位数由样本排序得出**（线性插值分位），不做解析近似；
- 默认 60 个样本，固定 seed；样本数与 seed 在返回体里可见。

## 7. 质量平衡审计（`auditMassBalance`）

COD/N/P 三本账的通用行式审计，输入是显式台账结构，WP2 全厂账本与 WP6 报表各自填账后调用：

```
残差 = 进水 − 出水 − 排泥 − 转化（氧化/反硝化/曝气）− 库存变化
残差% = |残差| / 进水 × 100
```

- 阈值默认 5%，可按账调整；
- 残差超阈值只返回**行级告警**（`alert: true`），不抛错——审计是诊断工具，不能让一条残差打断全厂报表；
- 非有限台账或负进水直接标告警，不参与百分比计算。

## 8. 路由契约

`src/server/routes/calibration.ts` 导出纯函数 `calibrationRoute(pathname, url, input)`：

- `GET /api/calibration/uncertainty?param=&from=&to=`
- 无标定结果 → 409 `CALIBRATION_INSUFFICIENT_DATA`；
- 不可辨识 → 409 `CALIBRATION_NOT_IDENTIFIABLE`，带原因列表；
- 正常返回：区间、相关矩阵、蒙特卡洛 P10/P50/P90、覆盖信息、`dataSource`；
- `param` 未知、`to < from`、非有限时间窗 → 400；
- 接线（在 `apiRoutes.ts` 调用）由集成方统一做，本模块不改 `apiRoutes.ts`。

服务层 `calibrationService.ts` 的标定结果摘要带 `uncertainty` 字段（区间/相关/覆盖信息/预测区间）；既有 WebSocket 进度事件与旧客户端字段保持不变。合成目标只有出水、没有剖面，按充分性门标为不可用并带原因，不返回假区间。

## 9. 合成验证结果（代理模型，非现场标定）

以下数字来自 `tests/uncertainty.test.ts` 的解析代理模型（单次求值 O(1)，不跑 BSM1 稳态仿真）：

| -------------------------------------- | ---------------------------------------------------------------------------------------------- |

| 90% 区间覆盖（mu_A，20 次重复）        | 19/20（门限 ≥ 14/20）                                                                          |
| 平行灵敏度参数相关 r(mu_A, b_A)        | −1.0000（强补偿负相关，`                                                                       | r   | > 0.5`） |
| 蒙特卡洛分位数（示例 seed=7，50 样本） | COD 17.88 / 22.62 / 26.26；NH 1.55 / 2.57 / 8.49；TN 8.82 / 10.51 / 11.81；TP 2.00（代理常量） |

这些只证明算法在合成数据上行为正确；**不代表任何真实水厂的参数区间已经标定完成**。

## 10. 未做项（本轮明确不承诺）

- **贝叶斯后验采样**：当前是频率派自助法 + 局部灵敏度，没有 MCMC/变分后验，不给后验概率分布；
- **多工况联合标定**：单数据集单点拟合，没有把冬夏/高低负荷多工况串成联合参数估计；
- **传感器误差传播完整闭环**：区间只传播参数不确定性，传感器噪声、漂移、死时间没有进入观测模型的误差链；
- **profile likelihood 区间**：未实现逐参数扫描重优化的似然区间；
- **现场数据接入**：观测台账导入、实验室报告对齐、采样口径核对属于现场验收门，不在本轮代码内。
