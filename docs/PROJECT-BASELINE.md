## 1. 当前核心状态

### 1.1 产品定位

AI 原生的污水厂全流程仿真平台：以工艺拓扑、进水边界、设备与仪表状态为输入，完成水线—泥线—回流—曝气的动态耦合推演，输出可追溯的水质、能耗、排放与操作建议；工程师可在关键节点干预，也可让 AI 在规则库和硬约束内自主推演。

当前实现仍是 **2D 工艺编排 + 数据面板 + AI 助手**，不是“3D 厂区 + 全自动无人闭环”的最终形态。

### 1.3 质量门禁现状

最近一次全量 `npx vitest run`（2026-11-24）：

| 指标 | 结果 |
|---|---|
| 测试文件 | 132 |
| 用例 | 1,617 |
| 通过 | 1,614 |
| 失败 | **3** |
| 预期失败占位 | 0（已全部改为普通 `it`） |
| `tsc --noEmit` | 通过 |
| 全量构建 / lint / prettier / jscpd | 本轮未最终复验 |

真实失败：

1. `tests/plantBoundary.test.ts` — 30 d 稳态 COD/N/P 三本账残差全部 <5% 且 `closed=true`。
2. `tests/plantBoundary.test.ts` — 三条除磷路径网络级对照（生物除磷开关、PAC、厌氧旁路可分辨）。
3. `tests/asm2dConservation.test.ts` — 闭合批次只投 `X_S` 时，水解+氨化释放的 NH₄ 应约等于 `X_S` 含氮量；当前 `ammonification` 计量为空，返回 `undefined`。

这意味着 **WP2 仍未达到“工业级可审计闭合”**，不能发布为 v0.10.0 正式版。

## 4. 迭代规划路线图

### M0 — 基线与语言决策（当前）

退出条件：

- 本文件与远程 `origin/main` 锚点一致；
- ADR-0001 语言选型通过；
- 黄金输入/输出向量冻结；
- WP2 三个红灯的根因有可复核记录。

### M1 — 确定性内核迁移

退出条件：

- 新内核通过 ASM1/ASM2d/ADM1/水力学/质量平衡的逐点 parity；
- 新旧内核在同一输入下出水、库存、三本账误差在约定容差内；
- 不引入 `unsafe`；无 panic 泄漏到服务层；fuzz/属性测试通过。

### M2 — 服务端与 AI 编排迁移

退出条件：

- HTTP/WS/协议/持久化接口契约不变；
- AI Provider、审计、限流、看门狗在目标语言中可用；
- 7×24 soak 测试通过，内存/句柄无增长。

### M3 — 3D 与全自动推演

退出条件：

- 3D 厂区与拓扑、实时状态、报警、操作联动；
- 规则库覆盖全部工艺分支与故障场景；
- 无人值守报告与人工干预均可复现。

### M4 — 工业验收与发布

退出条件：

- 现场验收门逐项完成；
- 全量压力/精度/合规报告归档；
- 5 社区上线；
- README、截图、回滚方案齐全。

## 5. 开源溯源与复用边界

### 5.1 模型来源

| 模型/算法 | 来源 | 复用方式 | 边界 |
|---|---|---|---|
| ASM1 / BSM1 | Henze et al., 1987；BSM1 基准报告 | 按公开论文/基准方程独立实现 | 不复制第三方代码；参数与状态方程在 `src/sim/asm1.ts`、`src/sim/bsm1.ts` |
| ASM2d | Henze et al., 1999 | 按标准矩阵独立实现 | 19 组分、生物除磷、PAO 储存池；实现自研 |
| ADM1 | Batstone et al., 2002 | 按标准矩阵独立实现 | 泥线消化；实现自研 |
| Takács 二沉池 | Takács et al., 1991 | 按公开模型独立实现 | 10 层固体通量；实现自研 |
| GB 18918-2002 | 国家标准 | 规则引擎与报表口径 | 不复制标准正文；仅引用限值 |

复用原则：

1. 只复用成熟底层能力，不引入与仿真核心无关的功能；
2. 所有第三方能力必须通过适配层与核心计算链路解耦；
3. 不把开源项目当图床、素材库或备份盘；
4. 新增依赖必须记录许可证、维护状态、替代方案与退出路径；
5. 详细审计见 `docs/REUSE-AUDIT.md` 与 `docs/DEPENDENCY-EVALUATION.md`。

## 6. 变更控制

- **单一事实源**：远程 `origin/main` + 本文件 + `CHANGELOG.md`。
- **每次提交**：必须写明影响的工作包、测试证据、未完成项；禁止用“预期失败”掩盖红灯。
- **文档同步**：接口、版本、验收阈值变更未同步文档的提交，不进入发布分支。
- **回滚**：任何迁移/重构必须保留上一版可运行产物与回滚脚本。
- **审计**：质量平衡、合规报表、协议写操作均保留输入、参数、输出、版本四元组。
