## P1 批量研究 studies API

新增持久 Study 父记录与原子入队：

- `POST /api/v1/studies`：一个 request 展开为 N 个可复现子实验；支持 `config`、RFC 7396 `config_patch`、`controls`（DO/内回流/RAS/WAS/PAC）、`replicates`、最多 4 个目标。
- 入队前一次性检查队列容量；容量不足返回 429，不会只入一半。
- `GET /api/v1/studies`、`GET /api/v1/studies/{id}`、`POST /api/v1/studies/{id}/cancel`、`GET /api/v1/studies/{id}/report.md`。
- 持久化表 `studies`：`id/name/spec_json/child_ids_json/created_at/updated_at/idempotency_key_hash/request_hash`；子实验仍是同一持久实验队列。
- 详情兼容字段：`createdAt`、`updatedAt`、`aggregate.status/progressPercent/total/succeeded/completed/failed/cancelled/best`、`children[].experimentId/variantIndex/replicate`。
- 目标支持 `score/passed/max_balance_residual_pct/effluent.cod|ss|nh4_n|nh|bod|tn|tp`；缺指标不伪造，报告写 `-`。
- 旧版 `ExperimentSpec` 中 V2 不能兑现的字段（如 `scenario`、`warmupDays`、`plantEnabled`）显式 422 `UNSUPPORTED_FIELD`，不静默忽略。

## P2 旧版只读迁移层

新增只读投影，不冒充 live tick：

- `GET /api/snapshot`：取最新成功实验，输出 `timeMin/influent/effluent/controls/score/margins/alarms/activeAlarms/health/scorecard/tanks/clarifier/massBalance/limits`；`compatibility.liveTick=false`。
- `GET /api/topology`：把最新实验请求配置翻译为旧 topology 形状；`compatibility.mode=translated-read-only`。
- `GET /api/metrics`：Prometheus 文本子集（version/queue/studies/uptime），注明没有旧版按路由 HTTP 计数器。
- `GET /api/history/snapshots`：成功实验历史投影。
- 没有成功实验时 `/api/snapshot` 返回 503 `NO_BASELINE`；能量、SRT、F/M 引擎未存，返回 `null` 并列入 `compatibility.missing`，不编造。
